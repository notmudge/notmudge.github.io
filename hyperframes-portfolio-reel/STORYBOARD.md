# Portfolio Reel Storyboard

## Format

- Duration: 20 seconds
- Canvas: 1920x1080
- Preview URL: `/hyperframes-portfolio-reel/`

## Beat 1 - Identity Lockup, 0-4s

Large name lockup over a fine data grid. Mono tag reads "Data & Insights Lead - Oxford". Small data nodes trace around the name.

Assets: typography, generated grid, subtle node field.

## Beat 2 - Practical Architecture, 4-8s

Three pillars appear: pipelines, models, reporting. A line travels from raw source to trusted output.

Assets: vector data-flow panels, tags from the skills section.

## Beat 3 - Featured Project, 8-13s

Weather Data Pipeline takes focus. The architecture path animates across Extract, Load, Transform, Gold Marts. Supporting stack tags appear.

Assets: WeatherCapture_dlt.png, DataFlowDiagram.png style references, recreated pipeline panels.

## Beat 4 - Selected Work, 13-17s

Three project cards fan into a structured grid: Sales Data Pipeline, Retail Data Warehouse, Spotify Data Warehouse. Each card gets a small proof tag.

Assets: project titles and stack tags from the portfolio.

## Beat 5 - Final Contact, 17-20s

Return to clean name lockup with URL and contact signal. Grid collapses into one blue underline.

Assets: portfolio URL and name.

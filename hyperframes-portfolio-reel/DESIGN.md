# Alex Mudge Portfolio Reel - Design Reference

## Style Prompt

A sharp, credible data portfolio reel for an Oxford-based Data & Insights Lead. The visual language should feel technical, practical, and composed: dark analytical canvas, precise cyan grid lines, terminal-inspired labels, data pipeline diagrams, and confident Ubuntu typography. Motion should suggest transformation from raw signals to reliable decisions.

## Colors

- Background: `#080b10`
- Surface: `#0d1117`
- Surface 2: `#131a24`
- Ink: `#e2e8f0`
- Muted text: `#94a3b8`
- Primary cyan: `#00e5ff`
- Violet accent: `#a78bfa`
- Amber accent: `#f59e0b`
- Deep panel: `#0b1220`

## Typography

- Display and interface: `Ubuntu`
- Code and data labels: `Ubuntu Mono`

## Motion Rules

- Use clean entrances from the site's existing reveal language.
- Data paths should draw on with line motion and small node pulses.
- Project cards should enter as evidence, not decoration.
- Numbers and tool tags should snap into place with short, precise timing.
- Keep transitions smooth: wipes, crossfades, and panel reveals.

## What NOT to Do

- Do not make it look like a generic tech startup ad.
- Do not overuse dark blue as the only palette.
- Do not bury the actual portfolio content under abstract visuals.
- Do not make text tiny; this is a video first.
- Do not use jump cuts between scenes.

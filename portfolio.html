01 — About

Delivery-minded
data and insights lead

I started in project management, where the work was about scope, people, timelines, and delivery. That still shapes how I approach data: define the problem clearly, build the right foundations, and make the output usable for the people making decisions.

Today I lead data and insights work while staying close to the build. I design pipelines, model data for reporting, and turn messy source systems into structured, explainable datasets.

My focus is practical architecture: Star Schema design, Python ETL, SQL modelling, dbt-style transformations, and trusted Power BI layers. Based in Oxford, I work with teams that need dependable data foundations and clearer decisions.

Azure · Featured Build

Weather Data Pipeline

End-to-end weather pipeline that collects hourly observations for five UK cities from Open-Meteo, lands raw JSON in ADLS Gen2, and loads curated records into Azure SQL. Transformations then shape the data into tested daily and monthly marts.

The project demonstrates the full path from raw API data to analytics-ready outputs: idempotent loads, rain/frost/snow day flags, scheduled GitHub Actions, and data quality checks.

# notmudge.github.io

Personal portfolio site for Alex Mudge, focused on data engineering, analytics engineering, data modelling, and BI project work.

## Featured Work

- [Weather Data Pipeline](https://github.com/notmudge/weather-project): Python, ADLS Gen2, Azure SQL, dbt, and GitHub Actions.
- [Sales Data Pipeline](https://github.com/notmudge/sales-data-pipeline): local Python ETL into a SQLite Star Schema.
- [Retail Data Warehouse](https://github.com/notmudge/retail-data-warehouse): SQL warehouse patterns, SCD Type 2, fiscal calendar, and analytical queries.
- [Spotify Data Warehouse](https://github.com/notmudge/Spotify-Data-Modeling-Solution): Power BI model cleanup and Star Schema solution.

## Local Preview

Open `index.html` in a browser, or serve the folder with any small static server.

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
